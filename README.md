# OpenAI ChatGPT 4o Demo Project

This is a Spring Boot REST API application that demonstrates a complete implementation developed using OpenAI ChatGPT 4o model.

## About

This application was fully completed using ChatGPT 4o.

## Implementation Details

For detailed information about the implementation, architecture, and development process, please refer to the article:

**[Implementation Article on Habr](https://habr.com/ru/articles/938022/)** *(Note: This article is written in Russian)*

## Project Overview

This application showcases a fully functional REST API with:
- Spring Boot 3.4.1 framework
- PostgreSQL database integration
- Data validation and JPA support
- CRUD operations with proper testing
- Database migrations with Liquibase

## Building and Running

### Prerequisites
- Java 21
- PostgreSQL
- Maven

### Build
```bash
./mvnw clean install
```

### Run
```bash
./mvnw spring-boot:run
```
